## 当前产品位置

Motto 是单仓自足的 Pi distribution：持续接纳 Pi core、session/provider/tool 契约和 extension
生态，同时由 Motto 掌握发行与产品呈现。实现顺序是 extension 优先，确需 core 时做解耦、可测、
登记 removalCondition 的最小改动。它不是把 Pi 换皮，也不是为了差异而分叉；长期价值在简约的
harness 与不随模型能力折旧的 TUI 版式。

## 下一阶段真实摩擦

运行中的 command/tool 目前可能先出现带背景的大块预览，完成后又收敛成无背景单行；同时
Working、原始 command 卡和 recap 可能重复出现。高度、背景与信息层级在生命周期内改变，造成
视觉跳跃和割裂。用户希望保留背景投影与涂乙式 diff 所形成的 Motto 陌生化语言，而不是把所有
活动压成普通日志；成功应安静，失败应强显，完整证据仍可取得。
