## 0. 定名与范围

把 thinking 显示从 pi 原生的**全有全无开关**（`hideThinkingBlock`，settings + Ctrl+T）
升级为**逐条三态披露**：

- **collapsed**：单行标签（如 `Thinking…`），可展开；
- **preview**：有界首尾摘要（head/tail 预算）；
- **full**：完整 thinking 原文。

关键属性：

- **per-entry**：以稳定 entryId 为键的 fold 状态，独立于全局 Ctrl+O 与
  hideThinkingBlock（后者保持兼容路径，本单不删除）；
- **fold 状态只属 UI**：不写入 session、不入模型上下文（I10 系列）；
- **identity 贯穿 streaming/resume**：同一 entry 在流式、恢复、折叠/展开间身份不变
  （TRANSCRIPT-PROJECTION 第四节）。

范围外，本单不做：turn reducer、Code Card、选区 sidecar、主题逐级槽、
全局 Ctrl+O 重构。

## 2. 施工切片

- **T2-1 thinking identity**：thinking 块获得稳定 entryId（流式/恢复同身份），
  fold 状态以 entryId 键存于 UI 层（不落 session）。
- **T2-2 三态渲染**：collapsed 标签 / preview 有界摘要 / full 原文；默认态 =
  collapsed（著录层纪律：thinking 归不著录之列）。
- **T2-3 交互键**：选中条目折叠/展开、独立 thinking 切换（替代/并存 Ctrl+T 全隐）。

## 3. 验收门

- 逐字节：session JSONL 与 `pi --export` 与官方基线等价（I0-1、I5、I10）。
- 基线：thinking collapsed/preview/full 三态新块入 `render-baseline.mjs`，
  `--check` 逐字节 PASS + 40/60/80/120/200 列四主题零超宽。
- 语义：fold 状态不写入 session 文件（appendCustomEntry 之外零新增写）、
  不入模型上下文（对 fixture 会话做 resume/export 断言）。
- 流式：thinking 流式期不闪变、不重排结构（I7-1）。
- 用色：仍只 text/dim/dimmer/accent，无新语义色（I8）。
- 交互面：Ghostty 用户侧记录（GHOSTTY-BASELINE，与 TUI-1 同表）。

## 5. 硬边界

- 不改 agent loop / provider / session canonical schema / 内置工具语义。
- 不重注册内置工具、不 shadow transcript、不手改 node_modules。
- 投影零写回、不入模型上下文；fold 是 UI 状态。
- 无 Motto 投影的组件逐字节回落原生；hideThinkingBlock 兼容路径不删。
