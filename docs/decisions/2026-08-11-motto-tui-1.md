## 0. 定名与范围

首单是**纯视觉投影**：在不改变会话语义与交互行为的前提下，把 transcript 从同权流水
改造成正文、著录、异常三层清晰的工作文面。per-entry thinking disclosure 属 MOTTO-TUI-2，
turn reducer 仍冻结（ROADMAP 观察期条款，唯一触发器是 usage-log 中可复现的目行粒度失准
记录）。

范围外，本单不做：per-entry 三态、Ctrl+O 重构、选区 sidecar、turn reducer、footer 与
composer 改造、新语义色、仿古元素、动画。Code Card 属已裁定 NO_GO，不得以 display-only
transformer 模拟（`tui-construction-prep.md` §1.4）。

## 1. 前置 P0：回归锚点稳定化（阻断项）

`TUI-THESIS` §12 以 `fixtures/tui/` 无头基线 diff 为 29 条自动验收不变量的缺省手段。
该手段当前不成立，三项实测：

1. **I0-2 幂等性不成立**。I0-2 宣称同一会话、同一终端宽度、同一主题、同一展开态下渲染
   输出逐字节一致，验收面标 A。在非 TTY 语境重跑 `render-baseline.mjs`，八个基线文件产生
   1937 增 / 1929 删。差异源为 OSC8 超链接随终端能力开关：已提交基线含序列体
   `]8;;https://pi.dev\链接]8;;\`，重跑版本落为纯文本 `链接 (https://pi.dev)`。四个受控
   变量之外尚有终端能力这一未受控变量。
2. **OSC8 剥离不完整**。`fixtures/tui/render-baseline.mjs:38` 注释称剥离 OSC 序列（含 OSC8
   链接），实际仅去除 ESC 字符，序列体留在「可读」基线内。
3. **无自动执行体**。`scripts/` 与 `.github/` 对 `render-baseline` 零引用；且该脚本为写入式，
   直接接入 CI 会自我覆盖基线，不构成比对。I9-1 逐宽度校验因此只是需要人记得手跑的检查，
   不是门禁。

P0 三项须在任何渲染路径改动之前完成：

- **P0-1** `render-baseline.mjs` 分 `--write` 与 `--check` 两态。`--check` 不写文件，与已提交
  基线逐字节比对，不一致即非零退出；逐宽度超宽校验并入该态。
- **P0-2** OSC8 归一：渲染前固定关闭超链接，或在剥离阶段完整移除 OSC8 序列，使输出不随
  终端能力变化。随后以 `--write` 重生成基线一次，commit 说明漂移理由（`fixtures/tui/README.md`
  基线漂移条款）。
- **P0-3** `--check` 接入 `scripts/ci-checks.sh`，与 drift-check 同级。

P0 全绿前不得改动任何 TUI 渲染路径。P0 本身为零产品行为改动，不入 PATCHES.json。

## 3. 验收门

每片须给出自动验收手段，缺省为基线 diff（P0 完成后该手段方才成立）。

- 逐字节：session JSONL 与 `pi --export` 输出与官方基线等价（I0-1、I5-1、I5-2、I10 系列）。
- 逐宽度：40/60/80/120/200 列四主题零超宽（I9-1，P0-3 后为自动门禁）。
- 层级：成功 turn 著录层仅一行摘要、assistant 最终回答任何展开态完整显示、collapsed 输出
  中失败条目仍出现（I1-1、I1-2、I1-3）。
- 用色：一处红、零装饰线、三级灰阶、无第四种红、无绿（I8-1、I3-2）。
- 流式：headings 投影在 `isStreaming: true` 时不变换（I7-1）。
- 交互面：Ghostty 用户侧记录（`GHOSTTY-BASELINE.md`），当前仍 DRAFT，属用户侧前置。

替代——无头基线不覆盖流式、拖选与折叠。

须登记 `docs/maintenance/PATCHES.json`，须有 removalCondition，须可独立回退；未登记的
Core 改动不得合入。上游优先仍然成立：可上游化的通用能力先提 issue 或 PR。#7721 定性为
未接纳、不可依赖，不得列为本单的前置或缓解依据。
