# 裁定：薄而自足 harness（2026-08-13）

> 本裁定是「发行与边界（凡例总纲第 7 条 / 宪制第 8 条）」的继续推进，不是推翻。
> 与既有立言的关系：凡例管「是什么」，PHILOSOPHY 管「为什么」，本裁定管「从现在起怎么做」。

## 一、定调

1. **core 权限开放**：自本裁定起，harness core 修改权限开放——motto 不再只是一系列
   extensions，而是**一个薄而自足的 harness**。废除「Core 改动只限 interactive 集成层与
   pi-tui 薄接缝」的既有边界（AGENTS-MOTTO 安全红线原措辞）。
   - 新纪律（解耦最小）：core 改动仍以**解耦方式**执行——组件级、可测试、登记 PATCHES、
     有 removalCondition、可独立回退；改动量最小必要，以实现宣言为界。
   - agent loop / provider / session canonical schema / 内置工具语义仍默认零修改；如确有
     改动必要，以独立裁定为之，不随日常施工夹带。

2. **折旧原则**：优先做**不随模型 agentic 能力提升而折旧**的设计。
   - 不折旧：版式、排版、信息呈现、目验标准、投影层——能力越强，这些越值钱；
   - 折旧：约束类 harness——因 agentic 能力不够而添加的 prompt 约束、防御性流程、
     行为矫正层。**当下正是弃置节点**：逐项清退，不新增。

3. **coding is cheaper → 取舍先于实现**：上下游功能实现与 copy 门槛已大幅降低，能力不再是
   稀缺品，**选择做什么**成为第一生产力。
   - 凡新议先问「做不做、为什么做、折旧吗」，再问「怎么做」；
   - 实现便宜不等于该做：准入仍守 ROADMAP 三类合法依据，实验便宜只降低试错成本，不降低
     立单门槛。

4. **TUI 版式学方法论（第一性原理）**：review flow 的陌生化 TUI 吸收「目录版本之学」的
   **原理层**——源流考辨（为什么这样排）与善本版式的人类目验标准（易读、留白、层级、不炫耀）。
   - 三不：**不借词语**（不用目录学名词装点文案）、**不借形体**（不仿线装/竖排等形制）、
     **不牵附**（不为典故而设计）；
   - 唯一准绳：人类目验 **clean and cool**——每个版式决定必须能讲出第一性原理的理由；
   - 「慎厥身修思永」：修身为本、图谋长远——设计取舍以长期不折旧为准。
