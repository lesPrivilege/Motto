### 2026-08-08 22:00 — 观察期第一条真实摩擦：收工 review 时 thinking 全文入流，纲要体不成立

- 场景：长会话收工 review——逐 turn 回看对话流复核工具轨迹与结论。deepseek max 思考下，
  每条 tool 目录行之间夹着整屏 thinking 独白正文，「汇总行 → 提要 → 展开」的纲要体被冲散，
  目录不再成立（需要反复滚过 thinking 才能串起 review 线）。
- 扩展/动作：motto-review-flow（turn 目录投影）+ pi 原生 assistant 渲染。
- 目标应用/环境：pi 0.84.1 regular TUI；ghostty。
- 现象：想做的做不到——收工 review 需要 thinking「默认收纳、按需展开」，而实际是全文平铺。
- 可逆性：UI 层不可逆（无逐条折叠）；配置层可规避（见处置）。
- 分类：落在观察期三类预设之外（①explore 洪流仍碎 → turn reducer 候选；
  ②必须离流审查的实际需求 → `/review` overlay 候选；③subagent 输出是否入目 → MOTTO.md 待验空白）。
  **补「非工具内容入流」一类**，本条为该类第一条。
- 疑似根因（当时体例假设，列为**被证伪项候选**）：`motto-review-flow-体例.md` 三.3
  「thinking 依 pi 原生折叠，不入目」假设 pi 原生折叠 thinking。核查证伪：pi 0.84.1
  **无 thinking 折叠**——仅一个 all-or-nothing 隐藏开关 `hideThinkingBlock`
  （默认 `false` = 全文），与 Ctrl+O 全局展开态不联动，且隐藏态无展开回看途径。
- 处置：**已配置解决**——`settings.json` 写入 `hideThinkingBlock: true`，thinking 收为单行
  「Thinking...」标签，收工 review 纲要体成立（真实 session 复核 13/13 通过）；
  Ctrl+T 可随时全局切换可见。注意：此为 hide-all，非 fold（不可逐条展开），
  边界记为上游证据。
